# 📅 تقویم و آب‌وهوا — اپلیکیشن اندروید

اپلیکیشن ساده، سبک و کاملاً فارسی برای نمایش **تقویم هجری شمسی** و **آب‌وهوای زندهٔ شهرهای ایران**.

> ✨ **نیازی به نصب اندروید استودیو ندارید!** کافی است این پروژه را در گیت‌هاب آپلود کنید؛
> سرویس GitHub Actions به‌صورت خودکار فایل **APK** را می‌سازد و برای دانلود آماده می‌کند.

## 🚀 روش اول (پیشنهادی): گرفتن APK با GitHub Actions — بدون اندروید استودیو

### گام ۱: ساخت مخزن (Repository)
1. وارد [github.com](https://github.com) شوید (اگر حساب ندارید ثبت‌نام کنید).
2. روی **+** بالای صفحه و سپس **New repository** کلیک کنید.
3. یک نام انتخاب کنید (مثلاً `calendar-weather`)، حالت را **Public** بگذارید و **Create repository** را بزنید.

### گام ۲: آپلود فایل‌های پروژه
1. در صفحهٔ مخزن روی **uploading an existing file** (یا Add file ← Upload files) کلیک کنید.
2. پوشهٔ ZIP دانلودشده را باز کنید و **محتویات داخل پوشه** را انتخاب کنید
   (یعنی پوشه‌های `.github` ،`app` و فایل‌های `build.gradle` و… — نه خود پوشهٔ بیرونی).
3. همه را بکشید و در صفحهٔ گیت‌هاب رها کنید.
4. روی **Commit changes** بزنید و چند لحظه صبر کنید.

> ⚠️ **خیلی مهم:** پوشهٔ `.github` باید دقیقاً در ریشهٔ مخزن باشد؛ در غیر این صورت بیلد خودکار اجرا نمی‌شود.
> اگر از طریق git آپلود می‌کنید: `git init` ← `git add .` ← `git commit -m "first commit"` ←
> `git branch -M main` ← `git remote add origin https://github.com/USERNAME/REPO.git` ← `git push -u origin main`

### گام ۳: بیلد خودکار
1. به تب **Actions** در بالای مخزن بروید.
2. بیلد با نام **Build Android APK** به‌صورت خودکار شروع می‌شود (حدود ۳ تا ۵ دقیقه).
3. وقتی دایرهٔ کنار بیلد **سبز ✔** شد، روی آن کلیک کنید.

### گام ۴: دانلود APK
1. در پایین صفحهٔ بیلد، بخش **Artifacts** را ببینید.
2. روی **calendar-weather-apk** کلیک کنید تا یک فایل ZIP دانلود شود.
3. ZIP را باز کنید؛ داخل آن فایل **app-debug.apk** قرار دارد. 🎉

### گام ۵: نصب روی گوشی
1. فایل APK را به گوشی منتقل کنید (کابل، تلگرام ذخیره‌شده، گوگل‌درایو و…).
2. روی فایل بزنید؛ اگر پیام «نصب از منابع ناشناس» آمد، آن را برای مرورگر/فایل‌منیجر مجاز کنید.
3. **Install** را بزنید. تمام! اپ روی گوشی شما نصب شد. 📲

> 💡 **نکته:** خود فایل Artifact یک ZIP است که APK داخلش است.
>
> 💡 **لینک دائمی می‌خواهید؟** در مخزن روی **Releases ← Create a new release** بزنید،
> تگی مثل `v1.0` بسازید؛ به‌محض انتشار تگ، APK مستقیماً در بخش Releases هم قرار می‌گیرد
> (این قابلیت در workflow از قبل تعبیه شده است).

## 🛠 روش دوم: بیلد با اندروید استودیو

1. پروژه را دانلود و از حالت ZIP خارج کنید.
2. در اندروید استودیو: **File ← Open** و پوشهٔ پروژه را باز کنید.
3. صبر کنید تا Gradle Sync تمام شود (به اینترنت نیاز دارد).
4. از منو: **Build ← Build Bundle(s) / APK(s) ← Build APK(s)**.
5. APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

```
.
├── .github/workflows/build-apk.yml   ← بیلد خودکار APK در گیت‌هاب
├── app/
│   ├── build.gradle                  ← تنظیمات ماژول اپ
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── java/ir/calendarweather/app/
│       │   ├── MainActivity.kt       ← منطق اصلی صفحه
│       │   ├── JalaliCalendar.kt     ← تبدیل دقیق میلادی ↔ شمسی
│       │   ├── Utils.kt              ← اعداد فارسی، نام ماه‌ها، رویدادها
│       │   ├── WeatherCodes.kt       ← نگاشت کد وضعیت هوا به ایموجی/متن فارسی
│       │   └── Cities.kt             ← لیست شهرها با مختصات
│       └── res/
│           ├── layout/               ← ظاهر صفحه‌ها
│           ├── values/               ← رنگ‌ها، متن‌ها، تم (روشن)
│           ├── values-night/         ← تم تاریک
│           └── drawable/ic_launcher.xml
├── build.gradle                      ← تنظیمات ریشه
├── settings.gradle
└── gradle.properties
```

## 🧩 شخصی‌سازی

| چه چیزی؟ | کجا؟ |
|---|---|
| افزودن/حذف شهر | `Cities.kt` — یک خط: `City("نام", عرض, طول)` |
| افزودن مناسبت | `Utils.kt` — داخل `JALALI_EVENTS` با کلید `ماه×۱۰۰+روز` |
| تغییر رنگ‌ها | `res/values/colors.xml` و `res/values-night/colors.xml` |

| تغییر شمارهٔ نسخه | `app/build.gradle` ← `versionName` / `versionCode` |

## ❓ سوالات متداول

**آیا APK این پروژه امن است؟**
بله؛ این همان APK استاندارد «debug» است که خود گیت‌هاب با کلید debug می‌سازد. برای انتشار در استور باید release امضاشده بسازید.

**چرا تعطیلات قمری (عید فطر، قربان، غدیر و…) نشان داده نمی‌شوند؟**
چون این مناسبت‌ها هر سال جابه‌جا می‌شوند و در تقویم قمری محاسباتی ICU ممکن است یک روز اختلاف داشته باشند. با این حال تاریخ قمریِ امروز در کارت تقویم نمایش داده می‌شود.

**بیلد در تب Actions اجرا نشد؟**
مطمئن شوید پوشهٔ `.github` در ریشهٔ مخزن است. در تب Actions اگر پیام داد، دکمهٔ **I understand my workflows, go ahead and enable them** را بزنید. بعد از هر Push یا با دکمهٔ **Run workflow** می‌توانید دوباره بیلد بگیرید.

**تغییرات جدید را چطور بیلد کنم؟**
بعد از Commit و Push، بیلد جدید خودکار اجرا می‌شود و Artifact تازه می‌سازد.
